# Fundraiser Platform

This repository contains a fundraiser platform with a React frontend and Node.js backend.

## Project Structure

- `client/` — React frontend
- `server/` — Express backend
- `docs/` — Documentation and architecture files

## Setup

1. Install dependencies in `client` and `server`.
2. Create `.env` in `server` with necessary environment variables.
3. Run `npm install` and then `npm start` in both directories.
